# Strivea Vet — prototype web

Prototype front-end statique de **Strivea Vet**, un SaaS vétérinaire pensé pour aider les cliniques à suivre les animaux après consultation, préparer les rendez-vous, piloter les protocoles Numa et centraliser les actions importantes.

Le projet actuel est volontairement simple : **HTML + CSS + JavaScript vanilla**, sans backend réel. Le code source est conservé tel quel pour pouvoir être repris facilement dans Claude Code ou dans un autre éditeur.
